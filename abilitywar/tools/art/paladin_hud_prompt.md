# 성기사 스킬 바 그림 부탁 (채찍이용)

첨부한 **수호기사 스킬 바 그림과 똑같은 배치**로 만들어 주세요 (가로로 긴 그림, 까만 배경).

- 위쪽 긴 띠: 왼쪽에 직업 이름 **「성기사」**, 띠 오른쪽 끝에 **T** 글자
- 띠 오른쪽의 작은 칸 1개 = **T 칸** (패시브)
- 아래 줄: 네모 칸 4개 (오른쪽 아래 구석에 **1 2 3 4** 글자) + 맨 오른쪽 큰 칸 1개 (**R**)
- 칸 크기·위치·간격은 수호기사 그림과 최대한 같게 (게임에서 칸 위치를 그대로 씀)

## 색과 느낌

하얀 대리석·은(`#F4F1E6`, `#C9D3E0`) + 밝은 금(`#FFD45A`) + 하늘빛(`#9FD8FF`). 왕국의 성기사, 거룩하고 눈부신 느낌.
테두리는 은빛 판에 금 장식과 작은 보석(하늘색). 배경은 짙은 남색~검정, 칸 안은 하얀 금빛으로 빛나는 그림.
위쪽 띠 오른쪽 끝 장식은 수호기사의 방패 대신 **위를 향해 세운 성검(십자 손잡이, 칼날에서 빛) + 그 뒤의 작은 왕관**.
무기는 방패가 아니라 **성검(크고 곧은 양손검, 금 십자 손잡이)** 이 중심이에요.

## 칸마다 그림

| 칸 | 스킬 | 그림 |
|---|---|---|
| **1** | 심판의 일격 | 위에서 땅으로 내리꽂히는 성검 + 땅에서 솟는 빛기둥과 갈라진 땅의 금빛 균열 |
| **2** | 신성한 방패 | 사람 실루엣 둘레를 감싸는 반투명한 금빛 방패막(구) + 흩어지는 검은 연기 (나쁜 효과가 지워짐) |
| **3** | 정화의 땅 | 땅에 꽂힌 성검 + 그 둘레로 퍼지는 금빛 원형 성역 무늬(마법진), 위로 올라가는 빛 입자 |
| **4** | 빛의 사슬 | 금빛 빛 사슬 여러 줄이 어두운 적 실루엣을 휘감아 묶는 모습 |
| **R** (큰 칸) | 성검강림 (聖劍降臨) | 구름을 가르며 하늘에서 내려오는 **거대한 빛의 성검** + 땅에 닿는 곳의 거대한 금빛 마법진과 사방으로 뻗는 빛살. 제일 화려하게 |
| **T** (작은 칸) | 성스러운 오라 | 무릎 꿇은 기사(또는 성검) 뒤로 둥글게 퍼지는 금빛 후광(오라) |

글자(1·2·3·4·R·T, 「성기사」)는 하얀 굵은 글씨, 검은 테두리.

## 참고: 실제 스킬 효과

| 키 | 스킬 | 효과 |
|---|---|---|
| 1 | 심판의 일격 | 앞으로 뛰어올라 성검을 내리꽂음. 반지름 3 피해 + 구속 + 빛기둥 |
| 2 | 신성한 방패 | 6칸 안 파티의 나쁜 효과를 지우고 보호막 + 수호 |
| 3 | 정화의 땅 | 성검을 땅에 꽂아 6초 동안 성역: 적은 피해 (언데드 2배), 아군은 회복 |
| 4 | 빛의 사슬 | 14칸 안 적 하나를 빛의 사슬로 묶어 속박 + 끌어당김 |
| R | 성검강림 (聖劍降臨) | 하늘에서 거대한 성검이 내려와 박힘. 큰 피해 + 기절, 아군 회복 |
| T | 성스러운 오라 | 켜기/끄기. 8칸 안 아군 받는 피해 -12%, 공격하면 아군 조금씩 회복 |
