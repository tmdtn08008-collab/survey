# 수호기사 스킬 바 그림 부탁 (채찍이용)

첨부한 천사 스킬 바 그림과 **똑같은 배치**로 만들어 주세요 (가로로 긴 그림, 까만 배경).

- 위쪽 긴 띠: 왼쪽에 직업 이름 **「수호기사」**, 띠 오른쪽 끝에 **T** 글자
- 띠 오른쪽의 작은 네모 칸 1개 = **T 칸** (패시브)
- 아래 줄: 네모 칸 4개 (오른쪽 아래 구석에 **1 2 3 4** 글자) + 맨 오른쪽 큰 칸 1개 (**R**)
- 칸 크기·위치·간격은 천사 그림과 최대한 같게 (게임에서 칸 위치를 그대로 씀)

## 색과 느낌

강철(은빛 푸른 회색 `#8FB8E8`) + 금(`#F0C860`). 묵직한 성기사·요새 느낌. 테두리는 두꺼운 금 장식 + 리벳 박힌 강철판.
배경은 짙은 남색~검정, 칸 안은 금빛으로 빛나는 그림.
위쪽 띠 오른쪽 끝 장식은 천사의 날개 대신 **커다란 방패(위는 평평하고 아래로 뾰족한 연 모양 방패)와 금 십자 문장**.

## 칸마다 그림

| 칸 | 스킬 | 그림 |
|---|---|---|
| **1** | 도발의 함성 | 금 십자 문장이 있는 방패 + 방패에서 사방으로 퍼지는 금빛 소리 고리 (적을 끌어들이는 함성) |
| **2** | 방패 돌진 | 비스듬히 앞으로 내민 방패 + 뒤로 길게 늘어지는 속도선과 먼지 (돌진) |
| **3** | 수호의 결계 | 땅에 꽂힌 방패 위로 덮이는 금빛 반구(돔) + 바닥의 마법진, 돔 안에 보호받는 사람 실루엣 |
| **4** | 대지 강타 | 위에서 내리찍는 방패 + 갈라지며 튀어 오르는 땅 조각과 금빛 충격파 |
| **R** (큰 칸) | 금성철벽 (金城鐵壁) | 하늘에서 내려와 땅에 박히는 **거대한 금빛 방패** + 사방으로 뻗는 빛살과 그 아래 금빛 반구 결계. 제일 화려하게 |
| **T** (작은 칸) | 수호 태세 | 방패 하나와 그 뒤의 동료 실루엣이 금빛 끈(사슬)으로 이어진 모습 (동료 대신 맞아 줌) |

글자(1·2·3·4·R·T, 「수호기사」)는 하얀 굵은 글씨, 검은 테두리.
