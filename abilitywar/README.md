# 능력대전쟁 (Ability War) — Minecraft 모드

능력을 하나 골라 싸우는 **능력대전쟁** 모드입니다. RPG 처럼 **1차 직업 → 전직 퀘스트 → 2차 직업** 으로 이어지는 직업 트리가 있습니다.

- **1차 직업** (처음 접속할 때 고름): ⚔ 전사 · 🔮 마법사 · 🛡 탱커 · ✚ 힐러
- **2차 직업** (레벨 30 + 전직 교관 퀘스트): 전사 → **마검사 · 혈귀 · 용기사** / 마법사 → **공허 · 흑마법사** / 탱커 → **🛡 수호기사** / 힐러 → **천사 · 성가사**
- 🆕 **3차 전직 "대"** (레벨 60 + 보스 퀘스트): **대마검사 · 대혈귀 · 대용기사 · 대공허 · 대흑마법사 · 대수호기사 · 대천사 · 대성가사 · 대성기사** — 피해·쿨타임·회복·버프가 모두 강해지고 금빛 오라와 이펙트가 붙습니다.
- 🆕 **⚜ 성기사** (특별 직업): 수도의 **왕** 에게 퀘스트를 받아 깨면 얻습니다 (전사·탱커·힐러, 레벨 40).
- 🆕 **몹 4종 + 보스 4종** (직접 만든 모델·공격 패턴·보스 바·등장 연출), 가끔 **야생에서도 보스가 나타남**, 다른 모드 보스도 목록에 넣을 수 있음.
- 🆕 **RPG 맵**: 새 월드를 만들면 스폰이 **둥근 겹 도시 「왕도 아르덴」** 이에요 (보내주신 그림처럼): 가운데 높이 올린 성채 위 **푸른 돔 왕궁**, 운하 고리 · 둥근 성벽 (푸른 원뿔 탑 20) · 해자 · 다리,
  집 수백 채로 꽉 찬 동네, **시장 광장**, **모험가 길드**. 성벽 밖 **「아르덴 왕령」** 에는 길 · 밭 · 풍차 · 목장 · 외곽 마을. 월드 곳곳에 **마을** 과 **던전 5종 (보스 제단)**.
- 🆕 **모험가 길드**: 접수원에게 가입하면 **F 등급** → E · D · C · B · A · S · SS · **SSS**. **자기 등급의 의뢰만** 받을 수 있고, 의뢰로 포인트를 모아 승급 심사.
- 🆕 **상점 · 강화 · 승급**: 시장 · 길드 · 마을 여관의 **물약 상인** 에게 회복 물약 · 물약을 사고, **대장장이** 에게 장비를 **+15 까지 강화**, +10 이 되면 **광물 + 몬스터 · 보스 전리품으로 다음 등급으로 승급**.
- 🆕 **돈 = G**: 에메랄드 대신 **G** 를 씁니다. 화면 **오른쪽 위에 가진 돈** 이 늘 보이고, 몬스터 · 보스 · 길드 의뢰로 법니다.
- 🆕 **보스 모드 4개** 를 `dist/boss_mods/` 에 같이 넣어 두었습니다: **Bosses of Mass Destruction** (보스 4) + **Marium's Soulslike Weaponry** (보스 8 + 전설 무기) + **The Graveyard** (묘지 · 지하 묘실 · 언데드 + 리치) + **Archon** (원소 마법 · 강령술 + 원소 보스 5). 야생 보스 · 던전 제단 · "보스 처치" 에 바로 함께 쓰입니다.
  **Ultris: Boss Expansion** (보스 8) 도 호환됩니다 (라이선스 때문에 [공식 페이지](https://modrinth.com/datapack/ultris) 에서 직접 받아 넣기).
- **레벨 (최대 100) · 경험치 · 스탯 포인트 (힘·민첩·지능·체력·지혜)**, **전직 교관 NPC**, 퀘스트 창, 직업 트리 화면
- RPG 를 위한 **8등급 장비 (무기 470개 + 갑옷 470세트)** — 등급마다 착용 레벨이 있습니다.
앞으로 알려주시는 능력들을 같은 구조로 계속 추가할 수 있게 만들어 두었습니다.

- 마인크래프트 **Java 1.20.1** / **Fabric**
- 필요한 것: [Fabric Loader](https://fabricmc.net/use/) 0.15 이상 + [Fabric API](https://modrinth.com/mod/fabric-api) (1.20.1용)
  (같이 넣은 보스 모드까지 쓰려면 **Fabric Loader 0.19.5 이상** + Fabric API 0.92.2 이상 — Soulslike Weaponry 가 필요로 함)
- 서버와 클라이언트 **둘 다** 설치해야 합니다 (멀티 서버면 서버 `mods` 폴더 + 각 플레이어 `mods` 폴더)

## 설치

1. Fabric Loader(1.20.1)를 설치합니다.
2. `mods` 폴더에 **Fabric API** 와 **`dist/abilitywar-2.5.0.jar`** 를 넣습니다.
   보스 모드도 쓰려면 **`dist/boss_mods/` 의 jar 12개**도 같이 넣습니다 (설명: `dist/boss_mods/README.md`).
3. 게임 실행 → 월드 접속 → 처음 들어오면 **1차 직업 선택 화면**이 뜹니다 (전사·마법사·탱커·힐러).
   관리자는 `/aw set <직업>` 으로 아무 직업이나 바로 지정할 수 있습니다: `warrior` `mage` `tank` `healer` / `void` `dragon` `blade` `blood` `cantor` `warlock` `angel` `guardian`

## 조작

| 키 | 동작 |
|---|---|
| **좌클릭** (맨손) | 평타 3연타 |
| **1 2 3 4** | 스킬 |
| **R** | 궁극기 (게이지가 가득 찼을 때) |
| **T** | 패시브 (공허: 그림자 이동 / 용기사: **꾹 눌러서** 용화 / 마검사: 잔영보 / 혈귀: 박쥐산개 / 성가사: 선율 전환 / 흑마법사: 영혼 수집 / 천사: 비행 ↔ 걷기 / 수호기사: 수호 태세 켜기·끄기 / 1차 직업: 회복·보호막) |
| **F** (누르고 있기) | 막기 |
| **Q** | 대시 (모든 능력 공통) |
| **B** | 직업 트리 (관리자 / 자유 선택 규칙이 켜져 있으면 눌러서 바로 변경) |
| **K** | 능력치 창 (스탯 포인트 찍기) |
| **J** | 퀘스트 창 (전직 퀘스트 진행 상황 · 포기) |
| **우클릭** (전직 교관에게) | 대화 · 퀘스트 받기 · 전직 |
| **G** | 흑마법서 (흑마법사: 해골 장비 / 영혼 목록 / 하수인 해제) |

- 능력을 고른 상태에서는 1·2·3·4 / R / T / F / Q 가 능력 키로 바뀝니다 (단축바 1~4, 채팅 T, 손 바꾸기 F, 버리기 Q 대신).
  아이템 버리기는 인벤토리 화면에서 Q 로 할 수 있습니다.
  채팅은 `/` 로 열거나, **설정 → 조작 → 능력대전쟁** 에서 키를 바꿀 수 있습니다. 능력을 해제하면 원래 키로 돌아옵니다.
- 손에 아이템을 들고 있으면 좌클릭은 원래 마인크래프트 공격이 됩니다 (평타 애니메이션은 맨손일 때).

## 🐉 용기사 (Dragon Knight) — 고룡의 계승자

근접 연계형, 난이도 높음. 발톱·날개·꼬리로 몰아치고, 스킬을 맞힐수록 **용혈 게이지**가 찹니다.

## 💀 흑마법사 (Warlock) — 소환 직업

하수인(해골, 되살린 몹)은 **내가 마지막으로 때린 적**을 노리고 (없으면 나를 때린 적), 할 일이 없으면 나를 따라다닙니다. 나와 **같은 팀**은 공격하지 않고 서로 피해도 주지 않습니다. 하수인은 햇빛에 타지 않고, 죽어도 아이템·경험치를 떨어뜨리지 않습니다.

## ⭐ 3차 전직 "대" (Grand)

2차 직업을 가진 채 **레벨 60** (게임 규칙 `abilitywarGrandLevel`) 이 되면 **전직 교관** 에게 3차 전직 퀘스트를 받을 수 있습니다.
퀘스트는 2차 직업마다 다르고, 모두 **보스 1마리 처치** 가 들어갑니다 (보스가 죽을 때 48칸 안에 있던 플레이어 모두 인정).

| 2차 | 3차 퀘스트 목표 |
|---|---|
| 마검사 | 적대적인 몹 150 · 보스 1 · 다이아몬드 8 |
| 혈귀 | 밤에 적대적인 몹 100 · 보스 1 · 가스트 눈물 4 |
| 용기사 | 블레이즈 30 · 보스 1 · 마그마 크림 16 |
| 공허 | 엔더맨 30 · 보스 1 · 엔더의 눈 12 |
| 흑마법사 | 언데드 120 · 보스 1 · 뼈 블록 16 |
| 수호기사 | 피해 받기/막기 3000 · 보스 1 · 철 블록 16 |
| 천사 | 체력 회복 1500 · 보스 1 · 황금 사과 4 |
| 성가사 | 같은 팀 버프 200 · 보스 1 · 자수정 조각 24 |
| 성기사 (왕) | 언데드 200 · 보스 2 · 불사의 토템 1 |

전직하면 직업 이름 앞에 **"대"** 가 붙고 (대마검사, 대천사 …) 스킬은 그대로 쓰면서 이렇게 강해집니다:

| 항목 | 3차 보너스 |
|---|---|
| 주는 피해 | ×1.3 |
| 받는 피해 | ×0.9 |
| 스킬 재사용 대기 | ×0.85 (1초 넘는 것만) |
| 궁극기 게이지 충전 | ×1.2 |
| 회복량 | +30% |
| 버프 지속 시간 | ×1.3 |
| 최대 체력 | +6 (하트 3칸) |

더 화려해지는 것: 발밑의 **금빛 마법진 오라**, 스킬을 쓸 때마다 금빛 파동, 궁극기 제목 뒤에 **금빛 인장**, 전직하는 순간 하늘에서 빛기둥 + "3차 전직 성공!" 연출. 다른 플레이어에게도 보입니다.
보상: 경험치 3000. `/aw grand true|false [플레이어]` 로 관리자가 직접 켜고 끌 수 있습니다.

## ⚜ 성기사 (Paladin) — 왕의 특별 직업

수도 「왕도 아르덴」 왕성 **왕좌의 방** 에 있는 **왕** (머리 위 `!`) 에게 우클릭하면 **왕의 서약** 퀘스트를 받을 수 있습니다.
조건: **레벨 40 이상**, 1차 직업이 **전사 · 탱커 · 힐러** (2차 전직을 했어도 됨). 목표: 언데드 60 · 보스 1 · 금 블록 4 → 보상: **성기사** + 경험치 1500.
레벨 60 이 되면 왕에게 다시 가서 **성검의 계승자** 퀘스트로 **대성기사** 가 됩니다. (왕은 관리자가 `/aw king` 이나 생성 알로도 놓을 수 있음)

성기사는 성검으로 싸우며 동료를 지키고 치유합니다. **언데드에게 피해 +50%**.

| 키 | 스킬 | 설명 |
|---|---|---|
| 1 | **심판의 일격** | 앞으로 뛰어올라 성검을 내리꽂음. 반지름 3 피해 6 + 구속 + 빛기둥. 8초 |
| 2 | **신성한 방패** | 6칸 안 파티의 나쁜 효과를 지우고 보호막 (흡수 II) + 수호 8초. 16초 |
| 3 | **정화의 땅** | 성검을 땅에 꽂아 6초 동안 반지름 5 성역: 적은 0.5초마다 피해 (언데드 2배), 아군은 회복 |
| 4 | **빛의 사슬** | 14칸 안 적 하나를 빛의 사슬로 묶어 2.5초 속박 + 피해 4 + 끌어당김. 12초 |
| R | **성검강림 (聖劍降臨)** | 연출: 하늘에서 거대한 성검이 내려와 박힘. 반지름 7 피해 18 + 2초 기절, 주변 아군 회복 |
| T | **성스러운 오라** | 켜기/끄기. 8칸 안 아군 받는 피해 -12%, 내 공격이 6칸 안 아군을 조금씩 회복 |

- 가운데: 6칸 높이 올린 **성채** (안쪽 둥근 성벽 + 푸른 원뿔 탑) 위에 **푸른 돔 왕궁** (석영 · 모서리 첨탑 4 · 현관 기둥) — 안은 **왕좌의 방** (붉은 융단, 기둥, 휘장, 샹들리에, 금 왕좌) 이고 **왕** 이 있음. 둘레는 정원 · 분수 2 · 생울타리 · 꽃밭
- 성채 → 안쪽 동네 → **운하 고리** (물, 다리, 난간 등불) → 바깥 동네 → **둥근 성벽** (높이 13, 위로 걸을 수 있음, 푸른 원뿔 탑 12 + 성문 탑 8) → **해자** (다리 4)
- 길: 성문 4개 (동서남북) 로 가는 **큰길 4** + **대각선 길 4** + **골목 8** + 둥근 길 3
- 남쪽: **스폰 광장** · **시장 광장** (노점 · 상인 주민) · 대장간 / 동쪽: **모험가 길드** (금빛 접수원) · 여관 / 서쪽: **전직 교관 회관** + 수련장 · **신전** / 북쪽: 병영 · 공원
- 나머지 땅은 **집 수백 채** 로 빽빽하게 (푸른·주황 구리 지붕, 1~3층, 성채 가까이는 흰 돌 저택). 건물마다 간판 (시장 · 모험가 길드 · 신전 · 여관 · 대장간 · 전직 교관)
- 시민 (주민) 과 경비 (철 골렘). **안전 지대**: 수도 · 마을 안에는 몬스터가 자연 생성되지 않고 야생 보스도 안 나옵니다.

**아르덴 왕령** — 성벽 밖 (수도 가운데에서 약 330칸까지). 들어가면 「아르덴 왕령」 이 뜹니다.

- 남·서·동 성문에서 뻗는 **구불구불한 길** (땅을 따라감, 물 위는 나무 다리, 가로등)

- 평평하고 물이 아닌 곳에만 지어서 월드마다 모양이 다릅니다.

## 🏰 모험가 길드

수도 동쪽의 **모험가 길드** (또는 마을마다 여관 안의 **길드 지부**) 에 있는 **접수원** (머리 위 `!`) 에게 우클릭하세요.

- **[길드 가입]** 을 누르면 **F 등급**. 등급: **F → E → D → C → B → A → S → SS → SSS**
- **자기 등급의 의뢰만** 받을 수 있습니다 (F 는 F 의뢰만, S 는 S 의뢰만). 길드 의뢰는 전직 퀘스트와 **따로** 하나씩 진행되고 (둘을 같이 해도 됨), 몇 번이든 다시 받을 수 있습니다.
- 의뢰를 끝내고 접수원에게 보고하면 **길드 포인트 · 경험치 · G** + 확률로 등급에 맞는 **장비**
- 이 등급에서 포인트를 다 모으고 레벨이 되면 **[승급 심사]** → 다음 등급 (화면 가운데 큰 등급 글자 + 연출, A 등급부터는 서버 전체 알림)
- 화면 왼쪽 위에 **등급 배지** (직업 이름 옆) 와 **길드 의뢰 추적**

| 등급 | 필요 레벨 | 승급 포인트 | 의뢰 보상 (포인트 · 경험치 · G · 장비) | 의뢰 예시 |
|---|---|---|---|---|
| F | 1 | 30 | 10 · 80 · 60 G · 일반 25% | 좀비 10, 거미 8, 밀 20, 고블린 6 |
| E | 5 | 48 | 12 · 200 · 120 G · 좋음 30% | 해골 12, 크리퍼 6, 가죽 12, 고블린 15 |
| D | 12 | 60 | 15 · 400 · 200 G · 좋음 35% | 밤의 언데드 20, 오크 6, 철 16, 마녀 3 |
| C | 20 | 80 | 20 · 700 · 320 G · 희귀 40% | 해골 기사 8, 엔더맨 6, 도깨비불 6, 금 16 |
| B | 30 | 100 | 25 · 1100 · 480 G · 희귀 45% | 블레이즈 10, 오크 15, 몬스터 60, 다이아몬드 3 |
| A | 40 | 120 | 30 · 1600 · 700 G · 영웅 50% | 위더 스켈레톤 10, 보스 1, 가스트 4, 엔더 진주 16 |
| S | 55 | 160 | 40 · 2400 · 1,000 G · 전설 60% | 보스 2, 타락한 기사왕, 몬스터 150, 서리 마녀 |
| SS | 70 | 200 | 50 · 3500 · 1,500 G · 신화 70% | 보스 3, 고대 비룡, 화염 거인, 네더라이트 파편 4 |

(필요 레벨 = 그 등급이 되려면 필요한 레벨. 승급 포인트 = 그 등급에서 다음 등급으로 오르는 데 필요한 포인트)

🆕 의뢰 보상에 **강화석** (등급 + 1 개) 도 들어오고, **A 등급부터는 보스의 영혼** (A · S 1 개, SS 2 개, SSS 3 개) 도 받습니다.

## ⚒ 돈 (G) · 상점 · 강화 · 승급

### 돈 (G)
- 에메랄드 대신 **G** 를 씁니다 (아이템이 아니라 플레이어마다 저장되는 돈). 화면 **오른쪽 위** 에 동전 + 가진 돈이 늘 보이고, 늘거나 줄면 그 아래에 **+25 G / -80 G** 가 떠오릅니다.
- 버는 법: **몬스터** 를 잡으면 최대 체력의 40% (좀비 8 G, 엔더맨 16 G), **보스** 는 근처에 있던 모두가 최대 체력 × 1.5 (최소 150 G), **길드 의뢰** 60 ~ 2,400 G.
- 예전에 모은 **에메랄드** 는 물약 상인 · 대장장이에게 **1 개 10 G** 에 팔 수 있습니다 (Shift + 누르기 = 전부).
- `/aw gold` 로 가진 돈 보기. 관리자: `/aw gold add|set|take <양> [플레이어]`.

### 대장장이: 강화 (+15 까지)
**수도 대장간 (남쪽 시장 옆) · 마을마다 대장간** 에 있습니다. 우클릭하면 강화 화면: 왼쪽에서 **내 장비** (가방 · 입은 갑옷 · 무기 470개 · 갑옷 1880개 모두) 를 고르고 **[강화하기]**.

- **무기**: 강화 1 마다 **공격력 +5%** (기본값 기준) · **능력 피해 +2%p** → +15 면 공격력 +75%, 능력 피해 +30%p
- **갑옷**: 강화 1 마다 **방어력 +5%** (부위 기본값, 최소 +0.25) · **최대 체력 +0.5**
- 이름 앞에 **+7** 처럼 붙고 (+10 부터 굵게, +12 금색, +15 붉은 금), 툴팁에 별 15칸 · 오른 능력치가 나옵니다. **+12 이상 성공은 서버 전체 알림**.
- 재료 = **강화석** + **G** (등급이 높을수록 · 강화가 높을수록 많이). 아래는 희귀 등급 기준:

| +2 → +3 | 100% | — | 2 | 120 G |

(이 모드 몬스터 · 보스 전리품은 **플레이어가 잡았을 때** 떨어집니다. 대장장이 화면의 **[재료 상점]** 에서 강화석 · 보호 주문서를 살 수 있습니다.)

## ⚔ RPG 장비

RPG 를 위한 무기와 방어구입니다. 등급은 8개이고, 등급마다 이름 색과 칸 배경색·툴팁 테두리 색이 다릅니다.

| 등급 | 색 | 무기 | 갑옷 세트 (부위 4개씩) | 특징 |
|---|---|---|---|---|
| 일반 | 회색 | 100 | 100 | 기본 능력치 |
| 좋음 | 초록 | 100 | 100 | 추가 능력치 1줄 |
| 희귀 | 파랑 | 100 | 100 | 추가 능력치 2줄, 칼날에 룬, 갑옷 세트 효과(능력치) |
| 영웅 | 보라 | 50 | 50 | **무기 특수 효과** (화염·번개 등) |
| 전설 | 주황 | 50 | 50 | 아이콘 빛 번짐, 갑옷 장식이 빛남, **세트 특수 효과** |
| 신화 | 빨강 | 50 | 50 | 아이콘이 반짝이는 애니메이션, 이름 색이 흐름 (엑스칼리버·궁니르·묠니르…) |
| 시크릿 | 청록↔금빛 | 10 | 10 | 고유한 이름과 설명, 무기 특수 효과 2개, 세트 효과 2개 |
| ? | 깜빡임 | 10 | 10 | 이름이 깨진 글자, **능력치가 ???** 로 보임, 무기는 공격할 때마다 무작위 효과(혼돈) |

모두 합쳐 **무기 470개 + 갑옷 470세트(1880부위)**. 부서지지 않고, 전설 이상은 불에 타지 않습니다.

- **얻는 법 (지금)**: 크리에이티브 탭 'RPG 장비 · 등급' (등급마다 탭 하나), 또는 `/aw gear <등급> [weapon|armor|set|all] [개수]` (OP).
  등급 키: `common good rare hero legendary mythic secret unknown`. 나중에 맵·몹·상자 드롭으로 연결할 수 있게 만들었습니다.
- **무기**: 검·대검·단검·도끼·전투 망치·창·낫·태도·레이피어·철퇴·지팡이·완드 12종. 손에 들면 공격력·공격 속도와 함께
  **능력 피해 / 치명타 확률 / 치명타 피해** 등이 붙습니다. **직업(능력)이 있으면 무기를 든 채로 좌클릭해도 능력 평타**가 나가고, 무기 능력치가 평타·스킬·궁극기에 모두 적용됩니다.
  지팡이·완드는 공격력이 낮은 대신 능력 피해가 높습니다.
- **추가 능력치**: 최대 체력, 이동 속도, 재사용 대기시간 감소, 흡혈, 궁극기 충전, 방어력, 치명타, 밀쳐내기 저항, 받는 피해 감소, 행운.
- **무기 특수 효과 (영웅 이상)**: 화염(불태움), 서리(느리게), 번개(번개 + 추가 피해), 출혈, 맹독, 쇠약, 흡혈, 신성(주변 아군 회복), 처형(체력 30% 이하 적에게 추가 피해),
  연쇄(옆 적에게 튐), 폭발(주변 피해), 공허(끌어당기기 + 어둠), 가속(스킬 쿨타임 감소), 광폭(힘).
- **갑옷 세트**: 같은 세트 4부위를 모두 입으면 세트 효과가 켜집니다 (툴팁에 '세트: 이름 (n/4)'). 희귀 이상은 능력치, 전설 이상은 특수 효과
  (재생, 화염 저항, 신속, 가시(근접 피해 30% 반사), 수호(30초마다 보호막), 밤눈, 물의 숨결, 도약, 강철 의지(저항), 치유의 오라).
  갑옷 모양은 12가지 (가죽·사슬·판금·로브·비늘·뼈·수정·기사·용·천사·악마·암살자) × 재료 색.
- 장비 정의는 `tools/gen_gear.py` 가 만든 `data/abilitywar/gear/gear.json` 에 있습니다 (이름·능력치·효과·그림을 한 번에 다시 생성).

## 처음 접속: 직업 선택

직업(능력)이 없는 플레이어가 서버에 처음 들어오면 **1차 직업 선택 화면** (전사·마법사·탱커·힐러) 이 뜹니다. 고르기 전에는 닫을 수 없고, 고른 직업은 저장되어
**다음에 접속할 때도 그 직업으로 시작**합니다. 게임 규칙 `abilitywarFirstJoinSelect`(기본 켜짐)로 끌 수 있습니다.
2차 직업은 위의 **전직 교관 퀘스트**로, 3차 "대" 전직은 레벨 60 에 다시 전직 교관에게서, 성기사는 **왕** 에게서 얻습니다.

## 화면 표시

- **오른쪽 아래 스킬 바** (능력마다 전용 그림): 1·2·3·4·R 아이콘. 쿨타임은 숫자가 아니라 **어두운 부채꼴이 시계방향으로 줄어드는 게이지**(빛나는 바늘 포함)로 표시되고, 다 차면 반짝이며 소리가 납니다.
  R 은 아래에서 차오르는 게이지, 가득 차면 은은하게 빛납니다.
- **패시브(T)** 는 위쪽 띠에 작게 표시 (공허: 그림자 속 남은 시간 / 용기사: T 를 꾹 누르는 동안 차오르는 빛, 용화 중에는 남은 용혈).
- **대시(Q)** 는 스킬 줄 왼쪽의 동그란 배지 (쿨타임 동안 테두리가 차오름). 스킬바 그림에 Q 칸이 있으면(용기사) 그 칸에 쿨타임이 표시됩니다.
- 키를 바꾸면 그림에 박힌 글자 위에 바뀐 키가 표시됩니다.
- **왼쪽 위 (RPG)**: 레벨 배지 · 직업(1차/2차) · 경험치 막대 · 남은 스탯 포인트 [K] · 진행 중인 전직 퀘스트 목표. 레벨 업하면 가운데에 LEVEL UP 알림.
- **궁극기 제목**은 능력마다 글자가 다릅니다: 용기사 = 한자(**古龍降臨**), 공허 = 영어(**EVENT HORIZON**), 마검사 = 한국어(**천지개벽**, 아래에 영어 HEAVEN SPLITTER), 혈귀 = 한자(**血月滿開**, 글자에서 피가 흘러내림 · 뒤에 핏빛 달), 성가사 = 라틴어(**GLORIA**, 금빛 세리프 + 빛살, 아래에 한국어 '천상의 합창'), 흑마법사 = 영어(**SOUL HARVEST**, 금 간 창백한 녹색 글자 + 피어오르는 영혼), 천사 = 한자(**天上審判**, 흰빛·금빛 글자 + 하늘에서 내려오는 빛줄기와 광륜, 아래에 한국어 '천상의 심판'), 수호기사 = 한자(**金城鐵壁**, 강철·금빛 글자 + 뒤의 방패 윤곽).
- 스킬 바 그림 바꾸기: `tools/art/<능력>_hud_source.png` 를 넣고 `tools/gen_hud.py` 에 슬롯 위치를 적은 뒤 실행하면
  `assets/abilitywar/hud/<능력>.json` + 텍스처가 만들어집니다 (그림이 없는 능력은 기본 스킬 바를 씀).
- **피해 숫자**: 때리면 상대 머리 위에, 맞으면 체력바 위에 깎인 체력이 뜹니다. 치명타(주황 !), 스킬(보라), 궁극기(분홍), "반격!", "막음", "연계!", "강인"(슈퍼아머) 표시.

게임 규칙: `abilitywarNoCooldown`(쿨타임 없음, 테스트용), `abilitywarSelfSelect`(**기본 꺼짐** — 켜면 B 직업 트리에서 누구나 아무 직업이나 바로 고름), `abilitywarCinematicRadius`(궁극기 연출 반경, 기본 10), `abilitywarUltChargePercent`(게이지 충전 배율 %), `abilitywarFirstJoinSelect`(처음 접속 시 직업 선택 화면),
`abilitywarJobLevel`(2차 전직 레벨, 기본 30), `abilitywarGrandLevel`(3차 전직 레벨, 기본 60), `abilitywarXpRate`(경험치 배율 %, 기본 100), `abilitywarGearLevel`(장비 착용 레벨 제한, 기본 켜짐),
`abilitywarWildBosses`(야생 보스, 기본 켜짐), `abilitywarWildBossChance`(야생 보스 확률 %, 기본 15).
`/team` 으로 같은 팀이 된 플레이어는 스킬에 맞지 않습니다.

## 애니메이션

모든 동작(평타, 달리기, 웅크리기, 점프, 막기, 대시(앞·뒤·왼쪽·오른쪽), 스킬, 궁극기, 그림자 이동, 맞았을 때 반응)에 **3인칭/1인칭 애니메이션**이 따로 있습니다.
- 3인칭: 몸통·팔·다리·머리 + 몸 전체(root) 키프레임. 팔과 머리는 몸통에 붙어서 같이 움직입니다.
- 1인칭: 양팔이 화면에 보이고, 카메라 흔들림/시야각 변화가 함께 들어갑니다.
- 다른 플레이어가 스킬에 맞으면 끌려감·붙잡힘·고개 젖혀짐·바닥에 쓰러짐·날아감·위로 띄워짐·블랙홀에 갇힘 동작이 나옵니다 (능력이 없는 플레이어도).
- 용기사의 날개·꼬리·발톱·비늘은 모델에 덧붙여 그리는 3D 부위라서 애니메이션 시간에 맞춰 펼쳐지고 휘두릅니다 (1인칭에서는 팔의 비늘과 발톱이 보임).
- 혈귀의 발톱·박쥐 날개는 3D 부위, 핏줄·붉은 눈은 스킨 위에 덧그린 4배 해상도 텍스처입니다. 박쥐산개 동안은 몸이 사라지고 박쥐 떼만 보입니다.
- 마검사의 검은 애니메이션의 `item` 본(1인칭은 `fp.item`)으로 손 기준 각도를 정합니다. 그래서 가로베기·올려베기·발도 자세(칼끝을 칼집 쪽으로)·거대화가 동작마다 다르게 잡힙니다.
- 애니메이션은 `assets/abilitywar/player_animations/*.json` 에 있고 **F3+T** 로 게임을 끄지 않고 다시 불러올 수 있습니다.
  `tools/gen_animations.py` 가 이 JSON 을 만드는 스크립트입니다 (형식 설명이 맨 위에 있음).

## 호환성

- 다른 모드 없이 Fabric API 만으로 동작합니다.
- 셰이더(Iris)·Sodium 과의 호환은 따로 테스트하지 않았습니다. 이펙트는 바닐라 셰이더 프로그램만 사용합니다.
