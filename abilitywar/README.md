# 능력대전쟁 (Ability War) — Minecraft 모드

능력을 하나 골라 싸우는 **능력대전쟁** 모드입니다. 지금 있는 능력은 **공허(Void)** 와 **🐉 용기사(Dragon Knight)** 입니다.
앞으로 알려주시는 능력들을 같은 구조로 계속 추가할 수 있게 만들어 두었습니다.

- 마인크래프트 **Java 1.20.1** / **Fabric**
- 필요한 것: [Fabric Loader](https://fabricmc.net/use/) 0.15 이상 + [Fabric API](https://modrinth.com/mod/fabric-api) (1.20.1용)
- 서버와 클라이언트 **둘 다** 설치해야 합니다 (멀티 서버면 서버 `mods` 폴더 + 각 플레이어 `mods` 폴더)

## 설치

1. Fabric Loader(1.20.1)를 설치합니다.
2. `mods` 폴더에 **Fabric API** 와 **`dist/abilitywar-1.2.0.jar`** 를 넣습니다.
3. 게임 실행 → 월드 접속 → **B 키**(능력 선택 화면)에서 능력을 고르거나 `/aw set void` / `/aw set dragon`

## 조작

| 키 | 동작 |
|---|---|
| **좌클릭** (맨손) | 평타 3연타 |
| **1 2 3 4** | 스킬 |
| **R** | 궁극기 (게이지가 가득 찼을 때) |
| **T** | 패시브 (공허: 그림자 이동 / 용기사: **꾹 눌러서** 용화) |
| **F** (누르고 있기) | 막기 |
| **Q** | 대시 (모든 능력 공통) |
| **B** | 능력 선택 화면 |

- 능력을 고른 상태에서는 1·2·3·4 / R / T / F / Q 가 능력 키로 바뀝니다 (단축바 1~4, 채팅 T, 손 바꾸기 F, 버리기 Q 대신).
  아이템 버리기는 인벤토리 화면에서 Q 로 할 수 있습니다.
  채팅은 `/` 로 열거나, **설정 → 조작 → 능력대전쟁** 에서 키를 바꿀 수 있습니다. 능력을 해제하면 원래 키로 돌아옵니다.
- 손에 아이템을 들고 있으면 좌클릭은 원래 마인크래프트 공격이 됩니다 (평타 애니메이션은 맨손일 때).

## 공허 (Void)

| | 이름 | 내용 | 피해 | 쿨타임 |
|---|---|---|---|---|
| 1 | **공허의 손아귀** | 공허 촉수로 적(18칸)을 끌어당긴 뒤 치명타. **1초 둔화 + 뇌진탕**(화면 흐림/겹쳐 보임/이명). 빗나가면 쿨타임 감소 | 6 | 9초 (빗나감 3.5초) |
| 2 | **공허 파동** | 주먹에 공허를 모았다가 폭발 — 앞쪽 적에게 큰 피해 + **멀리 날려버림** + 뇌진탕. 벽에 부딪히면 추가 피해 | 8 (+2) | 12초 |
| 3 | **공허 난무** | 적(20칸)에게 순간이동 → **4연타** → 바닥에 내리꽂기. 적이 땅에서 **3칸 이상 떠 있으면 바로 내리꽂고 같은 피해(10)** | 1.25×4 + 5 | 16초 |
| 4 | **공허 반격** | 0.8초 반격 자세. 이때 평타·스킬에 맞으면 **피해 무효** → 공허로 막고 **얼굴 강타** → **아래로 찍기**. 궁극기는 반격 불가. 실패하면 막는 모션만 | 4 + 4 | 8초 (실패 10초) |
| R | **사건의 지평선** | 게이지가 차면 사용. 블랙홀 소환 — 주변(14칸)을 빨아들이고, 중심에 붙잡히면 빠져나갈 수 없으며 **최대 체력의 75%** 를 잃음. **10블록 안의 플레이어는 궁극기 연출(시네마틱)** 을 보게 됨 | 최대 체력 75% | 게이지 |
| T | **그림자 이동** | 그림자 속으로 가라앉아(무적, 이동 속도 증가) 원하는 그림자에서 나옴: **다른 생명체의 그림자**(그 뒤에서 등장) 또는 **어두운 곳/하늘이 가려진 곳**. 최대 4초 | – | 12초 |
| F | **막기** | 앞에서 오는 평타 80%, 스킬 50% 감소 (잡기·궁극기는 못 막음). 막는 동안 느려짐 | – | – |
| Q | **대시** (공통) | 누르고 있는 이동키 방향(WASD, 없으면 앞)으로 약 6칸 돌진. 공중에서도 가능. 막기 중이면 막기를 풀고 대시. 공허는 보랏빛 잔상과 그림자가 남음 | – | 3초 |

- **궁극기 게이지**: 피해를 줄 때(피해량 ×4), 받을 때(×2.5), 시간(2초에 1)마다 찹니다. 100이 되면 R 칸이 빛납니다.
- 평타: 2.5 / 2.5 / 4.5 (3타째는 넉백).

## 🐉 용기사 (Dragon Knight) — 고룡의 계승자

근접 연계형, 난이도 높음. 발톱·날개·꼬리로 몰아치고, 스킬을 맞힐수록 **용혈 게이지**가 찹니다.

| | 이름 | 내용 | 피해 | 쿨타임 |
|---|---|---|---|---|
| 1 | **용조** | 앞으로 돌진하며 **두 번 할퀴고**, 마지막 타격으로 적을 **내 앞으로 끌어옴** + **용혈 표식**(10초). 공중의 적은 **위로 올려베어 더 띄움**. 표식이 있는 적에게는 표식을 터뜨리는 **강화 마지막 일격** | 2 + 2 + 2.5 (표식 5.5) | 7초 (빗나감 3초) |
| 2 | **용익타** | 등에 **거대한 날개**가 펼쳐지며 주변 적을 밀어내고(1.5), 날개로 앞을 후려쳐 **높이 띄움**. **용조를 맞힌 직후(2.5초 안)** 면 날개가 **두 번** 침 (연계!). 공중의 적은 **내 앞으로 끌어옴** | 1.5 + 5 (+3) | 9초 |
| 3 | **용왕난무** | 순식간에 접근 → **오른발톱 → 왼발톱 → 꼬리 후려치기 → 교차 발톱 내려찍기**. 공중의 적은 **따라 올라가** 마지막에 **땅으로 내리꽂음**. **용조 → 용익타를 연속으로 맞혔다면 불꽃 올려치기 추가타** | 2+2+2.5+4 (+3) | 12초 (빗나감 2초) |
| 4 | **역린 반격** | 0.8초 비늘 갑옷 반격 자세. 평타·스킬(궁극기 제외)에 맞으면 **무효** → **얼굴 할퀴기** → 등을 돌려 **꼬리로 땅에 처박기**. 성공하면 **용왕난무 쿨타임이 바로 초기화**(연계!). 실패하면 방어 자세만 (다른 모션) | 4 + 4 | 10초 (성공 7초) |
| R | **고룡 강림** | 용혈 게이지가 가득 차면 사용. 웅크려 힘을 모음 → 뒤에서 **거대한 고룡**(몸길이 약 25칸, 날개 폭 약 26칸)이 불길 속에서 솟아오름 → 앞몸을 일으켜 **포효로 적을 끌어당김** → **하늘로 도약** → 고룡이 **브레스** → **폭발 + 3초간 불타는 지면**. 10블록 안의 플레이어는 연출을 봄. **표식이 있는 적 추가 피해**, 잠깐 **슈퍼아머**(밀리지 않음·속박/뇌진탕 무시), 용혈 게이지를 **전부 소모** | 12 (표식 +6) + 화상 | 게이지 |
| T | **용화** | 용혈 게이지가 가득 찼을 때 **T 를 꾹(0.8초)** 누름. 팔에 **발톱**, 등에 **날개**, 몸에 **비늘과 빛나는 문양**, 엉덩이에 **꼬리**. 이동하면 **불꽃 잔상**. 평타가 **발톱 공격**으로 바뀌고 **모든 스킬 피해 1.25배 + 불붙임**, 이동 속도 +12%. 최대 20초 동안 게이지가 닳고, 다 닳으면 풀림. **용화 중 R** 은 남은 게이지로 바로 쓰는 마무리 (게이지를 다 쓰고 용화 해제, 궁극기 피해 1.25배) | – | 게이지 |
| F | **비늘 막기** | 공통 막기 (불꽃색 방패) | – | – |

- **용혈 게이지** (= 궁극기 게이지): 시간으로는 차지 않고, **스킬 적중**(용조 4/6, 용익타 2~6, 용왕난무 3씩 + 추가타 15), **연계 보너스**(용조→용익타 +10), **반격 성공 +30**, 평타(2, 용화 중 3), 맞을 때(체력 1당 1)로 찹니다.
- 평타: 사람 모습은 건틀릿 할퀴기 2.5 / 2.5 / 4 (3타는 내려찍기), 용화 중에는 발톱 3.5 / 3.5 / 5.5.
- 연계 판정 시간은 2.5초입니다. 연계가 들어가면 머리 위에 **"연계!"** 가 뜹니다.

## 화면 표시

- **오른쪽 아래 스킬 바** (능력마다 전용 그림): 1·2·3·4·R 아이콘. 쿨타임은 숫자가 아니라 **어두운 부채꼴이 시계방향으로 줄어드는 게이지**(빛나는 바늘 포함)로 표시되고, 다 차면 반짝이며 소리가 납니다.
  R 은 아래에서 차오르는 게이지, 가득 차면 은은하게 빛납니다.
- **패시브(T)** 는 위쪽 띠에 작게 표시 (공허: 그림자 속 남은 시간 / 용기사: T 를 꾹 누르는 동안 차오르는 빛, 용화 중에는 남은 용혈).
- **대시(Q)** 는 스킬 줄 왼쪽의 동그란 배지 (쿨타임 동안 테두리가 차오름). 스킬바 그림에 Q 칸이 있으면(용기사) 그 칸에 쿨타임이 표시됩니다.
- 키를 바꾸면 그림에 박힌 글자 위에 바뀐 키가 표시됩니다.
- **궁극기 제목**은 능력마다 글자가 다릅니다: 용기사 = 한자(**古龍降臨**), 공허 = 영어(**EVENT HORIZON**), 아래에 한국어 이름.
- 스킬 바 그림 바꾸기: `tools/art/<능력>_hud_source.png` 를 넣고 `tools/gen_hud.py` 에 슬롯 위치를 적은 뒤 실행하면
  `assets/abilitywar/hud/<능력>.json` + 텍스처가 만들어집니다 (그림이 없는 능력은 기본 스킬 바를 씀).
- **피해 숫자**: 때리면 상대 머리 위에, 맞으면 체력바 위에 깎인 체력이 뜹니다. 치명타(주황 !), 스킬(보라), 궁극기(분홍), "반격!", "막음", "연계!", "강인"(슈퍼아머) 표시.

## 명령어 (`/abilitywar` = `/aw` = `/능력`)

| 명령 | 설명 |
|---|---|
| `/aw list` | 능력 목록 |
| `/aw set <능력> [플레이어]` | 능력 지정 (다른 사람 지정은 OP) |
| `/aw clear [플레이어]` | 능력 해제 |
| `/aw charge [플레이어] [양]` | 궁극기 게이지 채우기 (OP) |
| `/aw reset [플레이어]` | 쿨타임 초기화 (OP) |

게임 규칙: `abilitywarNoCooldown`(쿨타임 없음, 테스트용), `abilitywarSelfSelect`(B 화면으로 직접 선택 허용), `abilitywarCinematicRadius`(궁극기 연출 반경, 기본 10), `abilitywarUltChargePercent`(게이지 충전 배율 %).
`/team` 으로 같은 팀이 된 플레이어는 스킬에 맞지 않습니다.

## 애니메이션

모든 동작(평타, 달리기, 웅크리기, 점프, 막기, 대시(앞·뒤·왼쪽·오른쪽), 스킬, 궁극기, 그림자 이동, 맞았을 때 반응)에 **3인칭/1인칭 애니메이션**이 따로 있습니다.
- 3인칭: 몸통·팔·다리·머리 + 몸 전체(root) 키프레임. 팔과 머리는 몸통에 붙어서 같이 움직입니다.
- 1인칭: 양팔이 화면에 보이고, 카메라 흔들림/시야각 변화가 함께 들어갑니다.
- 다른 플레이어가 스킬에 맞으면 끌려감·붙잡힘·고개 젖혀짐·바닥에 쓰러짐·날아감·위로 띄워짐·블랙홀에 갇힘 동작이 나옵니다 (능력이 없는 플레이어도).
- 용기사의 날개·꼬리·발톱·비늘은 모델에 덧붙여 그리는 3D 부위라서 애니메이션 시간에 맞춰 펼쳐지고 휘두릅니다 (1인칭에서는 팔의 비늘과 발톱이 보임).
- 애니메이션은 `assets/abilitywar/player_animations/*.json` 에 있고 **F3+T** 로 게임을 끄지 않고 다시 불러올 수 있습니다.
  `tools/gen_animations.py` 가 이 JSON 을 만드는 스크립트입니다 (형식 설명이 맨 위에 있음).

## 호환성

- 다른 모드 없이 Fabric API 만으로 동작합니다.
- 셰이더(Iris)·Sodium 과의 호환은 따로 테스트하지 않았습니다. 이펙트는 바닐라 셰이더 프로그램만 사용합니다.

```
./gradlew build          # build/libs/abilitywar-1.2.0.jar
./gradlew runClient      # 개발 클라이언트
python3 tools/gen_textures.py     # 이펙트/아이콘 텍스처 다시 생성
python3 tools/gen_animations.py   # 애니메이션 JSON 다시 생성
python3 tools/gen_dragon_textures.py  # 용기사 날개/비늘/꼬리/불꽃 텍스처
python3 tools/import_hud_art.py <그림> tools/art/<능력>_hud_source.png   # 체크무늬(가짜 투명) 배경 지우기
python3 tools/gen_hud.py dragon   # 스킬바 텍스처/마스크/아이콘/카드
python3 tools/gen_titles.py       # 궁극기 제목 그림 (용기사 = 한자, 공허 = 영어)
bash tools/gen_sounds.sh          # 합성 효과음 다시 생성
```

새 능력 추가: `com.abilitywar.ability.Ability` 를 상속한 클래스를 만들고 `Abilities.init()` 에서 등록 →
아이콘(`textures/gui/<키>_skill1.png` …), 애니메이션(`<키>.idle`, `<키>.attack1` …), 번역(`ability.abilitywar.<키>`)을 추가하면 됩니다.
